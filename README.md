# Сайт Юлии Шабашовой

Статический сайт: пять страниц плюс три юридических документа. Никакой сборки — папку можно выложить как есть.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Залейте в него содержимое этой папки (файл `index.html` должен лежать в корне репозитория).
3. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Если удобнее держать сайт в подпапке, положите её содержимое в `docs/` и выберите в настройках Pages папку `/docs`.

## Свой домен

Settings → Pages → Custom domain, вписать домен. Затем у регистратора добавить запись CNAME на `<логин>.github.io`.

| `index.html` | Главная |

## Что внутри

- `styles.css` + `tokens/` — цвета, типографика, тени, анимация. Единая точка правки оформления.
- `landing.css` — верстка страниц сайта.
- `ds-bundle.js` — библиотека компонентов (кнопки, поля, карточки).
- `app.js` — секции страниц (главная, курсы, кейсы, документы).
- `assets/` — фотографии, иконки, обложки.

Шрифты Cormorant и Montserrat подгружаются с Google Fonts, React — с unpkg. Интернет при просмотре нужен.

## Локальный просмотр

Открыть `index.html` двойным щелчком не получится: браузер запрещает подгружать соседние файлы с диска. Запустите простой сервер из этой папки:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Что доделать перед запуском

- Форма заявки ничего не отправляет — нужно подключить приём заявок (почта, CRM или Telegram-бот).
- Ссылки на соцсети и почту в подвале проверить на актуальность.
- Обложки кейсов сейчас одинаковые, заменить на настоящие.

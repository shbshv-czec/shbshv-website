# Сайт Юлии Шабашовой

Статический сайт на [Astro](https://astro.build): пять страниц плюс три юридических документа.
Страницы собираются в чистый HTML заранее — в браузер уезжает ~25 КБ кода,
поэтому сайт открывается быстро даже на слабом мобильном интернете.

## Публикация

Сайт публикуется сам: при каждом пуше в ветку `main` GitHub Actions собирает
проект и выкладывает на GitHub Pages (`.github/workflows/deploy.yml`).
Адрес: `https://shbshv-czec.github.io/shbshv-website/`.

## Локальная работа

```
npm install
npm run dev        # живой предпросмотр на http://localhost:4321
npm run build      # сборка в dist/
npm run preview    # предпросмотр собранного сайта
```

## Структура

| Где | Что это |
| --- | --- |
| `src/pages/` | Страницы: главная, курсы, кейсы, документы. Одна страница — один файл |
| `src/components/` | Шапка, подвал, отзывы, иконки, разворот кейса, юридическая страница |
| `src/layouts/Base.astro` | Общий каркас: head, фон, cookie-бар, тост |
| `src/styles/` | Токены бренда, стили страниц, компоненты дизайн-системы |
| `src/scripts/site.js` | Весь интерактив — один маленький ванильный скрипт |
| `src/data/` | Тексты юридических документов |
| `public/assets/` | Фотографии, иконки, обложки |

Шрифты Cormorant и Montserrat лежат в самом сайте (@fontsource) — внешних
запросов к Google Fonts нет, интернет для просмотра нужен только к самому сайту.

## Тексты

Тексты страниц лежат прямо в файлах `src/pages/*.astro` (константы вверху файла)
и в `src/data/legal-*.mjs` (документы). Правишь текст → пуш в `main` → сайт
обновится сам через минуту-две.

## Что доделать перед запуском

- Форма заявки ничего не отправляет — нужно подключить приём заявок (почта, CRM или Telegram-бот).
- Ссылки на соцсети и почту в подвале проверить на актуальность.
- Обложки кейсов сейчас одинаковые, заменить на настоящие.
- Приём оплаты на странице курсов — пока заглушка с уведомлением.
- Привязку фото к площадкам в табло «Где меня слушали» проверить (src/pages/index.astro, константа VENUES).
